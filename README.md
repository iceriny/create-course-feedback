# 课程反馈生成工具

面向教师的本地课程反馈工作台。记录每位学生的课堂表现，生成并校对反馈，再按自定义模板复制。

## 使用流程

1. 选择或新建班级，填写本次课程、授课时间、内容和教学目标。复用历史课程不会改变本次日期。
2. 在“管理名单”粘贴学生姓名。支持换行、英文或中文逗号、顿号和制表符，同名学生可以分别记录。这里也可以设置班级默认记录方式并应用到全班。
3. 选择学生填写课堂观察。用 `Ctrl+Enter` 跳到下一位待记录的学生，刷新后可以接着编辑上次选中的学生。
4. 生成区会列出需要补齐的课程信息。首次配置时，在设置中选择服务、粘贴密钥，再点“测试并保存”。生成区支持批量生成、更新和重试。
5. 在正文中直接校对，点击“确认并下一位”跳到下一份待校对的反馈。补充课堂观察或修改课程后，可以更新反馈，也可以手动核对原稿再确认。
6. 选择纯文本或 Markdown 复制。打开“逐人复制”可以接着处理尚未复制的已确认反馈，也可以整班复制。反馈模板的修改会实时显示在家长预览中。
7. “开始新课”会归档本次记录。在“历史课次”里可以查看、复制旧反馈、复用教案或继续编辑某节课。

复制成功只表示内容已进入剪贴板，不表示已经发送给家长。

## 常用时间、多人编辑与语音

- 在授课时间旁打开“常用时间”，保存当前时段。每个班级可保存多个备选，点击“设为默认”后，新课会自动填写当天的默认时段；已有课次保留原时间。支持“昨天”“上周”“本日”快捷切换，其中昨天与上周以当前所选日期为基准。
- “多人编辑”可按名单搜索和状态筛选同时展示多位学生的观察与反馈，每页可选 6、10、16、24 或 50 人。切回“逐人编辑”可继续校对同一份记录。
- 点击表现输入框即可查看两组补全。“历史记录”来自该学生已保存的课次，“启发提示”参考其他学生所有已保存课次、本次观察及常用表达。输入文字后按文字相似度排列，选择后填入当前栏，使用前请核对是否符合本次表现。
- 聚焦课堂观察输入框后，长按框内的麦克风按钮或直接长按文本区开始语音输入，松手结束。普通话转写会在光标处实时显示，确认后的文字保存到草稿。浏览器需要支持语音识别并获得麦克风权限。不支持时可使用系统输入法语音。
- 页面右上角可选择浅色、暗色或跟随系统，选择会在此设备保留。

## 数据与备份

课程草稿、名单和设置保存在浏览器本地，常用短语保存在 IndexedDB。切班与刷新可恢复未完成草稿。学生通过稳定身份关联输入、结果与任务，排序不会改变归属。

设置中的“下载备份”包含课程、历史课次、名单、反馈、模板和常用短语，API 密钥单独保存在设备上。保存失败或同班多个页面发生保存冲突时，可直接“下载当前草稿”。恢复前会显示数据数量，恢复文件中的同名记录会覆盖当前记录。

生成时，课程背景和当前学生观察会发送给所选 AI 服务。基础内容检查用于提醒明显问题，最终反馈需要教师核对。

## 本地开发

项目使用 React、TypeScript、Ant Design、Zustand、Dexie 和 Vite。保留 Yarn 4 锁文件。

Node.js 要求 `^20.19.0 || >=22.12.0`。

```sh
yarn install
yarn dev
```

验证与构建：

```sh
yarn test
yarn lint
yarn build
```

## 代码结构

```text
src/
  components/
    workspace/   工作台、学生导航、进度与批量操作
    course/      课程信息与时间选择
    student/     学生编辑与表现提示
    settings/    设置与反馈模板
    common/      通用按钮、图标与语音输入
    layout/      页面框架
    updates/     更新提示
    dev/         开发诊断组件
  types/         共享类型
  constants/     提示词等常量
  domain/        课程、学生与生成规则
  services/      AI、持久化、反馈模板与版本服务
  store/         页面状态
  hooks/         通用 React hooks
  motion/        工作台动效引擎、共享卡片转场与内容折叠
  utils/         通用工具
  AI_API/        AI 服务请求适配
```

测试与对应实现放在同一目录。性能监控使用 `import.meta.env.DEV` 判断开发环境；`PerformanceMonitor` 与 `LazyIcons` 目前作为备用组件保留，未接入页面。

### 交互动效

动效参数集中在 `src/motion/engine.ts`。按钮按压后的回位使用轻回弹弹簧。名单位移、面板展开和卡片移位使用临界阻尼弹簧，文字在停止位置保持稳定。CSS 和 Web Animations 共用采样曲线，系统开启“减少动态效果”时直接呈现目标状态。

逐人编辑使用 `EditorStage` 在同一平面横向换人。改变布局或名单顺序前先读取卡片的屏幕位置，再移动到新位置。逐人和多人布局切换时，表单按目标尺寸排版一次，内容随卡片背板的伸展逐步露出。快速反向会接续正在移动的卡片。摘要与表单通过 `Disclosure` 沿高度展开，浮层通过 `useOverlay` 保留离场内容，浮层内换页由 `ContentTransition` 区分前进、返回和原位替换。移除学生时该行先退出，后续行再补位。确认反馈时进度栏显示对应学生，正文在流式生成与校对之间保持原位。

投影由上方同一光源产生。每档依次绘制贴近边缘的接触阴影、向下偏移的主体投影与范围最大的环境阴影。浅色与深色使用相同的偏移、模糊半径和扩散值。

| 高度 | 使用位置 |
| --- | --- |
| 1 | 按钮等贴近表面的控件 |
| 2 | 课程、名单、学生编辑卡片 |
| 3 | 吸顶工具栏与底部操作栏 |
| 4 | 下拉菜单、日期面板、气泡等锚定浮层 |
| 5 | 模态窗口和设置抽屉 |

按钮悬停时升高一档，按下时落回承载表面。工具栏吸附在视窗边缘内侧时显出第三档投影。对话框内的下拉菜单以对话框为承载面，菜单投影落在对话框上。

## 本地模拟 AI 验收

```sh
node scripts/mock-ai.mjs
```

在本地开发页面设置自定义服务。

- 生成地址 `http://127.0.0.1:5199/v1/chat/completions`
- 模型列表地址 `http://127.0.0.1:5199/v1/models`
- 密钥填写任意测试字符串，无需真实密钥
- `local-test` 返回模拟流；`slow-test` 返回较慢的流；`error-test` 模拟 401 错误
- 选择模型后点击“测试并保存”，成功后可以返回工作区

模拟服务只监听本机，不发送外部请求。测试后切回实际使用的服务。
