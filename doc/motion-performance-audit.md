# 工作台动效性能验收

2026-11-25。本次使用隔离的 Chrome 会话、本地数据和生产构建。采样覆盖 9 人分项记录、50 人多人页、48 人长反馈历史和 390 像素窄屏。桌面样本使用 60 Hz 浏览器时钟，同一项的修改前后使用相同视口、数据和操作。不同项目的采样窗口不同。

| 交互 | 观察结果 |
| --- | --- |
| 本次课程展开、收起 | 9 人多人页上，三次展开的主线程累计耗时中位数从 269 ms 降到 85 ms，收起从 249 ms 降到 115 ms。累计值取自每次点击后的 420 ms 窗口。表单高度连续变化，名单和编辑区从原位置移到新位置。中途反向时，工具栏与卡片的间距偏差在 1 px 以内。 |
| 返回已有完整课程 | 新浏览器会话中首次展开峰帧从 30 ms 降到 20 ms；再次展开从 39 ms 降到 18 ms。验证了课程名称、时间控件、历史教案复用及减少动态效果。 |
| 名单选择、排序、筛选与吸顶 | 检查了 9 人、50 人的逐人前进与返回、近跳与远跳、搜索、筛选、排序和滚轮停靠。最终样本中，选择首帧为 13–24 ms，筛选与恢复首帧为 19–35 ms，长名单滚动与吸顶的最大帧间隔约 19 ms。 |
| 多人页远跳与分页 | 50 人页跳到同一位学生时，730 ms 内主线程累计占用从 582 ms 降到 108 ms。沿途表单挂载和回收从 16 次和 10 次降到 1 次和 0 次，目标可立即输入。下一页过渡期间挂载的真实表单从 6 张降到 1 张，其余在结束后逐帧接入。 |
| 管理名单 | 50 人名单中输入 9 个字的脚本耗时从 206 ms 降到 25–32 ms。删除时先观察被删除行退出，再验证余下行补位和数据归属。 |
| 观察模式、生成详情、行标尺 | 简要与分项切换、生成详情开收的第 95 百分位帧间隔约 16.8 ms。连续拖动行标尺 48 次的累计布局耗时从 10.61 ms 降到 6.97 ms。 |
| 语音、生成、确认和保存 | 20 条模拟语音增量期间，弹窗恒定为 376 px 高。24 段本地模拟流式响应到确认的过程中，正文保持同一输入框，采样的绘制事件从 315 次降至 276 次。验证了确认后聚焦下一位、进度提示退出、草稿由保存中变为已保存。 |
| 历史详情与连续复制 | 48 人长反馈在首屏附近实际布局 2 行；进入详情的累计布局约从 33–35 ms 降至 11.6 ms，峰帧从 50.1 ms 降至 33.4 ms。滚到最后一行仍能预览该学生的正文。返回课次、连续复制、格式切换及嵌套 Escape 均已验证。 |
| 设置、模板、日期与菜单 | 16 项浮层交互各测三次。14 项的峰帧中位数约 16.8–16.9 ms。设置冷开和长历史详情打开各有一帧超过 24 ms。日期首次挂载比重开耗时高，日期面板进退本身在最终样本中没有超过 24 ms 的帧间隔。 |
| 外观与控件反馈 | 明暗切换时，按钮、输入框、选择器和状态标签会同时创建大量颜色、边框与阴影过渡。现在一次提交整套配色，并保留浮层位移与图标反馈。9 人多人页样本里切深色峰帧从 105 ms 降至 44 ms，切浅色从 76 ms 降至 27 ms。单独采样按钮悬停、按下与释放时，峰帧为 17 ms。 |

最终样本中，首次新建班级的最长帧为 150 ms，开始新课为 54 ms，切回已有班级为 65 ms。另一次冷启动采样将 150.3 ms 间隔定位在首次操作之前。验证也覆盖了在 48 个教案中搜索并复用、收起含日期弹层的课程表单，以及版本更新窗口的关闭。语音与生成测试使用模拟识别事件与本地流式响应，窄屏结果来自 Chrome 视口模拟。
