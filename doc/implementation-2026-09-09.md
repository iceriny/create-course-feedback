# 本轮实施与验收

范围为可靠性修复、校对交付工作流、视觉与性能优化。未加入语音、云同步、多人协作、历史趋势或模型局部改写等扩展功能。修改在本地工作区，未提交或发布线上。

## 已落实

- 学生稳定 ID；排序、增员、改名与同名学生均保留各自观察和反馈。
- 课次自动保存、切班恢复、刷新恢复、保存失败状态；开始新一课归档旧记录，支持恢复历史课次。
- 任务去重、课次和学生身份回写校验、取消与旧响应隔离；重做保留旧稿。
- SSE 跨块缓冲、UTF-8 解码、HTTP 错误分类、120 秒超时、3 路并发、失败重试和 Retry-After 等待。等待重试时可以取消。
- 空观察不生成；反馈可手工编辑；确认并下一位；失败项筛选与重试；纯文本及 Markdown 最终预览。
- 批量复制只包含已确认、启用、非失败且非生成中的非空内容；复制成功后才记录复制时间。
- 密钥遮蔽、按服务分别保存、测试连接；模板编辑保留。备份包含原始字符串、JSON、课次和 IndexedDB 短语，排除密钥；导入预览和失败回滚。
- 桌面名单导航与单人工作区，窄屏单列；可收起课程信息；操作文案、禁用状态、进度、键盘焦点和减少动态效果设置。
- 删除本轮替代后不再使用的旧学生卡片、表单导航和浮动复制组件，保留无关代码与依赖。

## 浏览器验收

使用本机开发页面、虚构班级和学生完成以下操作：

1. 输入 Zoe/Amy 各自观察、排序、选择学生，确认观察仍属于原学生。
2. 刷新后恢复课程、观察与手工反馈。
3. 确认并下一位，批量预览只包含已确认的人；复制成功提示正常。
4. 通过 `scripts/mock-ai.mjs` 验证设置保存、连接测试、实际 HTTP/SSE 流式展示、完成状态、停止生成及保留原稿。未调用真实 AI 提供商。
5. 开始新一课后内容清空、名单保留；历史课次恢复正文和确认状态。
6. 100 人名单搜索跳到第 100 人并录入；Ctrl+Enter 切换并聚焦下一个人的输入。
7. 390、768、1440px 界面检查；实测 document 宽度与可视区域分别为 375/375、753/753、1425/1425，无横向溢出（扣除滚动条）。

## 性能证据

| 指标 | 审查时 | 本轮完成 |
| --- | --- | --- |
| 主体 JS gzip | 主要入口及 vendor 约 365 kB | 入口 274.80 kB，运行时 0.36 kB |
| 存储依赖 | 混在初始 vendor | 单独的 db 30.71 kB gzip，存储封装 0.37 kB，异步加载 |
| 设置与模板 | 未打开也挂载并预加载 | 打开时加载，分别约 9.43 / 1.15 kB gzip |
| 学生编辑区 | 所有学生卡片挂载 | 百人名单实测只有 1 个编辑器、5 个观察字段 |
| 流式预览更新 | 每片段写入状态 | 每 60ms 合并更新；模拟 3 路流同窗 300 次片段回调，仅 3 次预览更新 |

流测试分别在 10、30、100 人队列运行，通过并发数量和更新次数断言。首屏异步加载短语时仍会下载 db 分块，不能把入口体积降幅直接当作首次总流量或加载时间降幅。未采集线上 LCP/INP、真实教师操作耗时或各家 AI 的真实网络延迟。

## 后续使用

本地开发服务可预览修改。真实生成需要在设置中选回实际服务并填写密钥，建议先用一份非敏感观察验证自己的模型。模拟服务不访问外部网络。浏览器验收留下的是虚构测试数据，不影响线上域名的数据。

持久化仍属于当前浏览器设备；清除网站数据前应下载备份。服务商兼容性已在传输层与本地模拟链路验证，真实服务的配额、可用模型和内容质量需使用者的服务配置验证。
